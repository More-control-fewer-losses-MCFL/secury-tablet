# Architecture Decision Records

Registrar aqui decisões arquiteturais relevantes quando houver uma decisão real.
Antes, consultar ../arquitetura.md e documentos existentes para evitar duplicação.
Usar número sequencial, contexto, alternativas, decisão, estado (proposta/aceita/
substituída), consequências e referência à aprovação quando necessária.

Este ciclo mantém a arquitetura existente. O mecanismo seguro de autenticação de
professores ainda está em discussão; nenhuma alternativa foi declarada aprovada.
